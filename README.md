# Blockbloom Project(GDG Summer Project)

## Overview
The Blockbloom project is a blockchain development journey that covers key concepts and practical implementations in blockchain technology. This project includes learning about Bitcoin, Ethereum, the Ethereum Virtual Machine (EVM), minting tokens, and building decentralized applications (DApps) etc.

## Key Highlights
1. **Bitcoin and Proof of Work**:
   - Implemented a basic version of Proof of Work (PoW) to find the nonce for a given message string.
   - Explored the fundamentals of Bitcoin's consensus mechanism.

2. **Ethereum and Smart Contracts**:
   - Gained an understanding of Ethereum and its ecosystem.
   - Learned about the Ethereum Virtual Machine (EVM) and its role in executing smart contracts.

3. **Token Standards**:
   - Minted tokens using ERC-721 and ERC-1155 standards with OpenZeppelin libraries.
   - Explored the differences between fungible and non-fungible tokens.

4. **Solidity Programming**:
   - Learned Solidity, the programming language for writing smart contracts.
   - Implemented various smart contracts to understand Solidity's syntax and features.

5. **Final Project - OLX DApp**:
   - Built a decentralized application (DApp) similar to OLX for buying and selling items.
   - Integrated blockchain technology to ensure transparency and immutability.
