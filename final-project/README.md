# OLX DApp: Decentralized Marketplace for Buying and Selling

---

## 🚀 Features

- **Post Products:** Easily list items for sale with details like name, description, price, category, and image URL.
- **Buy Products:** Purchase listed products directly by interacting with the blockchain.
- **MetaMask Integration:** Connect your Ethereum wallet to interact with the platform.
- **Transparency:** All transactions and listings are securely stored on the blockchain.
- **Decentralized Ownership:** Buyers and sellers interact directly without intermediaries.

---

## 🛠️ Tech Stack

- **Frontend:** React.js(Vite Project)
- **Smart Contracts:** Solidity,Hardhat
- **Blockchain Network:** Ethereum
- **Wallet Integration:** MetaMask
- **Library for Blockchain Interaction from frontend:** ethers.js

---

## Requirements
- **Node**
- **hardhat** : npm install hardhat(in hardhat folder)
- **ethers** : npm install ethers(in DApp folder i.e. do cd DApp)
- **Metamask Wallet**
